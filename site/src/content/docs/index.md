## 🌳 절차 한 줄 요약

```
사건 → 고소장 → 경찰수사
 ├─ 송치 → 검찰 → 기소 → 1심 → 2심 → 3심 → 유/무죄
 │ └ 불기소 → 항고/재정신청
 └─ 불송치 → 이의신청(90일) → 검찰
```

---

## 🔑 가장 헷갈리는 3쌍

1. **무혐의 ≠ 무죄** — 무혐의는 검찰 처분, 무죄는 법원 판결
2. **고소 ≠ 고발** — 고소는 피해자, 고발은 제3자
3. **송치 ≠ 기소** — 송치는 경찰→검찰, 기소는 검찰→법원
