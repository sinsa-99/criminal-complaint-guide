> 💡 **고소 = 형사 출발점**. 민사로 돈 받기는 별도 진행. 두 트랙은 동시에 가능하고, 형사 유죄는 민사에서 강력한 증거가 됨. → 자세한 비교: [용어사전 ⓪-3](/glossary/#-3-고소-vs-민사소송-vs-형사소송--가장-중요한-비교)

## 🌳 절차 한 줄 요약

```
사건 → 고소장 → 경찰수사
 ├─ 송치 → 검찰 → 기소 → 1심 → 2심 → 3심 → 유/무죄
 │ └ 불기소 → 항고/재정신청
 └─ 불송치 → 이의신청(90일) → 검찰
```

---

## 🔑 가장 헷갈리는 3쌍

1. **무혐의 ≠ 무죄** — 무혐의는 검찰 처분, 무죄는 법원 판결
2. **고소 ≠ 고발** — 고소는 피해자, 고발은 제3자
3. **송치 ≠ 기소** — 송치는 경찰→검찰, 기소는 검찰→법원
